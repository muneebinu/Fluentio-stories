# Fluentio Stories

A clean, mobile-friendly German reading platform for learners from A1 to B2.

## First release

- Browse reading material by CEFR level.
- Read in a distraction-free layout.
- Tap a German word to look up its meaning and basic word information.
- No accounts or registration in the first release.

## Content and attribution

Stories will be linked or embedded from their original publishers where permitted. Text will only be reproduced when its licence or permission allows it. Free access does not automatically grant republication rights.

## Technology

Built with React and Vite, with GitHub Pages deployment.
