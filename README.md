# Fluentio Stories

A responsive German reading workspace for learners from A1 to B2.

## Current first-release features

- Browse a directory of external German-reading publishers and learning resources.
- Filter the directory by CEFR level and search by source.
- Open a distraction-free reader.
- Paste German text or import a plain-text `.txt` file.
- Tap individual German words to request an English translation and a German Wiktionary entry.
- No accounts or registration.

## Content and attribution

The source directory links to original publishers. Fluentio Stories does not copy or scrape third-party stories. Free-to-read does not automatically mean free to republish. Use the reader with your own text, public-domain material, or text whose licence permits this use. Otherwise, read the content on the publisher's own website.

## Dictionary limitations

Translation and dictionary information use free third-party services and may be rate-limited or unavailable. Results depend on context. This first version does not guarantee automatic lemma detection or structured noun gender/plural and verb-form analysis.

## Technology

React + Vite. GitHub Pages deployment is configured as a manual workflow and will be enabled when launch is ready.
